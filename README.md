# 🌐 Urvesh Rane — Bespoke 3D Portfolio

> A high-end, human-crafted 3D portfolio website built with **React**, **React Three Fiber (Three.js)**, and **GSAP**. Features an antigravity dark-mode space with weightless floating geometry, interactive mouse parallax, custom cursor physics, and kinetic typography.

## ⚡ Highlights

- **Anti-Generic Aesthetic**: Custom typography pairings (*Syne*, *Space Grotesk*, *JetBrains Mono*), asymmetrical grid structures, and procedural SVG grain textures.
- **Interactive 3D Space**: 180 floating particle field, procedural wireframe polyhedra (icosahedra, octahedra, torus knots), orbital rings, and coordinate grid plane reacting to mouse and scroll velocity.
- **Antigravity Floating Portrait**: Real-time 3D tilt tracking with elastic physics, live status badge, and hairline targeting reticles.
- **Kinetic Scroll Animations**: GSAP ScrollTrigger timeline reveals, word-by-word text scrubbing, and staggered metric counters.
- **Momentum Scrolling**: Integrated Lenis smooth scroll engine synced with GSAP's animation ticker.
- **Dual-Layer Custom Cursor**: Reactive dot and delayed ring operating in `difference` blend mode.

## 🛠️ Tech Stack

- **Core Framework**: React 19, Vite
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animation & FX**: GSAP, ScrollTrigger, Lenis Smooth Scroll
- **Typography**: Syne, Space Grotesk, JetBrains Mono
- **Deployment Target**: Cloudflare Pages / Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Urvesh3206/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:5173`.

### Production Build

```bash
npm run build
```

The compiled assets will be ready in the `dist/` directory.
